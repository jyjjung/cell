
# em. portal

A high-performance community portal built with NextJS, Firebase, and Tailwind CSS.

## Features
- Real-time Chat
- Bible Reading Plan tracking
- Community Rosters & Events
- PWA Support for mobile installation

## Development
To get started, run:
```bash
npm run dev
```

If you encounter `ChunkLoadError` in development, please perform a hard refresh (Ctrl+Shift+R) as the PWA service worker may be caching old assets.
