# **App Name**: Cell Dates

## Core Features:

- Event Display: Display events in chronological order with details like QT, Events, Birthdays, and Snacks.
- Bible Reading Plan Generator: Automatically format a multi-day bible reading plan tool based on user input, with each day consisting of four lines, excluding Sundays.
- Date Selection: Allow users to choose a starting date for the bible reading plan, dynamically adjusting the displayed dates accordingly.
- Admin Protection: Implement admin access using a simple password ("Admin123") for editing events and managing content.
- Event Management: Provide a clean, intuitive interface for admin users to easily add, edit, and remove events.

## Style Guidelines:

- Primary color: A deep indigo (#3F51B5) to evoke a sense of modernity and depth.
- Background color: A very dark, desaturated blue-gray (#212121) to support the dark, minimalist aesthetic.
- Accent color: A vibrant violet (#BA68C8) to draw attention to interactive elements and important dates.
- Use a clean, sans-serif font for readability on dark backgrounds.
- Minimalist layout with a focus on content hierarchy and easy navigation.
- Subtle, slow-moving background animations to enhance the modern feel.
